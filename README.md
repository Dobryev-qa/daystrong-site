# DayStrong Site

Public legal and support pages for the DayStrong iOS app.

Expected GitHub Pages URLs:

- `https://dobryev-qa.github.io/daystrong-site/privacy/`
- `https://dobryev-qa.github.io/daystrong-site/terms/`
- `https://dobryev-qa.github.io/daystrong-site/support/`

## Publish

1. Create a public GitHub repository named `daystrong-site` under `Dobryev-qa`.
2. Push this folder to the repository default branch.
3. Enable GitHub Pages from the repository settings using the default branch root.
4. Verify the three URLs above return HTTP 200.
5. Configure the app with the verified URLs.
